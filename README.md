Project Title:AI Resume & Job Description Analyzer

Description:

AI Resume & Job Description Analyzer is a Python-based web application developed using Streamlit and Google Gemini AI. It allows users to upload their resumes in PDF format and compare them with a given job description. The application generates an AI-based match percentage, identifies strengths and weaknesses, and provides an interactive chatbot to answer resume-related questions.

Technologies Used: Python, Streamlit, Google Gemini API, PyPDF2, Matplotlib.

GitHub: https://github.com/devasriyandamuri-cloud/AI-Resume-Analyzer
